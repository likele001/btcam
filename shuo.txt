## 文档一：2D 数控 CAM 桌面软件【需求规格说明书】

项目名称：自研 CAM 切割排料软件（对标 AlphaCAM，适配雕刻机、绘图仪、裁割设备）
项目形态：Windows 独立桌面 exe 软件（Tauri 2.0 打包）
技术栈：Tauri2 (Rust 壳) + React+TS+Vite+PixiJS (前端画布 UI) + FastAPI (Python 后端) + OCCT 几何内核 + DeepNest 排料引擎 + SQLite 本地存储
运行要求：离线优先、可选择对接 CenkorMes / LightMes
目标用途：DXF/DWG 图纸导入、图形修复、刀具工艺管理、板材排板、2D 轮廓刀路生成、后处理输出 NC / PLT / CUT 文件给机床

### 1 业务总流程

导入图纸 → 图形自动校验修复 → 选择刀具 / 加载工艺模板 → 设置板材尺寸、边距余量 → 零件排版（手动 / 自动排料） → 整张板材刀路计算、路径预览 → 切割顺序优化、添加微连接 → 选择对应机床后处理 → 导出加工文件 → 工单方案本地存档（可选同步 MES）

### 2 功能需求清单

#### 2.1 图形导入与预处理模块

1. 支持导入：DXF（优先）、DWG，支持批量多零件导入
2. 自动几何修复：断线合并、剔除微小碎线、清除重叠线段、自动闭合开放轮廓、区分外轮廓 / 内孔轮廓
3. 图形基础编辑：平移、旋转、缩放、镜像、删除、框选
4. 图形校验提示：自相交轮廓弹窗告警，标记异常线段位置

#### 2.2 刀具库与工艺模板模块

1. 刀具分类
   - 铣刀：平底刀、锥刀、球刀；参数：直径、刀尖圆角
   - 线切割钼丝：丝径、放电补偿间隙
2. 刀具工艺参数：进给速度、下刀速度、抬刀高度、安全高度、顺铣 / 逆铣方向
3. 工艺模板：按物料分类（密度板、无纺布、多层板等），保存整套刀具 + 补偿参数，一键加载
4. 刀路计算自动读取刀具参数，完成轮廓偏移补偿，禁止手动修改原始图形做补偿

#### 2.3 板材与排料模块

1. 板材参数：自定义宽高、四边预留余量、零件最小间距
2. 手动排板：鼠标拖拽零件、自由旋转、锁定零件位置、单独选中编辑
3. 自动排料：调用 DeepNest 引擎，自动排布，支持锁定零件旋转角度（木纹限制）；自动计算板材利用率
4. 整板合并：排料完成后，所有零件作为整体，统一生成一套连续刀路
5. 支持余料保存，余料可作为板材再次投料排板

#### 2.4 刀路生成模块（2D 轮廓切割，暂不开发 3D 浮雕）

1. 刀路类型：外轮廓切割、内孔切割
2. 刀路配置项：起割点手动指定、微连接（桥接）添加、切割方向（顺时针 / 逆时针）
3. 路径优化：自动排序切割顺序，最小化空程抬刀距离
4. 预览规则：实线 = 切割轨迹、虚线 = 抬刀空走路径、标记起割点；支持缩放平移查看路径

#### 2.5 后处理系统（核心机床对接模块）

设计原则：后处理为独立配置文件，新增机床只增加配置，不修改刀路内核代码

1. 内置后处理模板
   - 维宏 / 新代 / 山龙雕刻机：输出 `.nc` G 代码
   - 绘图仪：输出 HPGL `.plt`
   - 裁割设备：输出兼容 AlphaCAM 格式 `.cut`
   - 通用导出：导出原始 DXF 图形文件
2. 后处理自定义能力
   - 可编辑程序头、程序尾、换刀 M 代码、行号开关、小数精度
   - 支持单板材导出、批量多板材一次性导出加工文件
3. 导出文件直接 U 盘上机，无需二次转换

#### 2.6 工单存档（本地 SQLite）

1. 保存内容：零件图形、板材参数、排板布局、刀具工艺、刀路参数、加工文件路径
2. 检索功能：按工件名称、日期检索历史工单方案，支持重复打开编辑
3. MES 对接（可选扩展）：向 CenkorMes/LightMes 推送工单、用料统计、加工文件归档；从 MES 拉取工单零件清单

#### 2.7 软件基础能力

1. 离线优先，断网可完整使用全部 CAM 功能；联网才同步 MES
2. 画布操作：缩放、平移、框选；支持自定义快捷键，对齐 AlphaCAM 操作习惯
3. 打包为单 exe，免安装，双击直接运行；自带版本信息
4. 日志面板：输出图形报错、排料进度、刀路计算日志

### 3 性能硬性指标（验收标准）

1. UI 界面不卡死，后台计算运行时前端画布、菜单可正常操作，异步进度提示
2. 单板材≤50 个异形零件：自动排料 + 刀路总耗时 ≤ 10s
3. 上万线段大图纸：画布平移、缩放无明显拖影卡顿
4. 内存上限：老 Win7 双核电脑，稳定运行内存 ≤180MB
5. Tauri Release 编译，关闭调试符号，opt-level=3 优化

### 4 分阶段迭代计划

#### V0.1 最小可用版本（优先交付，能上机干活）

- Tauri+React+PixiJS 画布基础壳，窗口、图层、缩放拖拽
- FastAPI 后端基础框架，DXF 解析、基础轮廓修复
- 手动排板：零件拖拽、旋转、锁定
- 基础轮廓刀路 + 刀具半径补偿（OCCT）
- 第一版后处理：维宏 NC G 代码导出、DXF 导出
验收标准：导入 DXF、手动排一张板、输出 NC，雕刻机可正常切割

#### V0.2 CAM 核心补齐版本

- OCCT 深度集成，完善轮廓偏移、自相交检查修复
- 接入 DeepNest 自动排料引擎
- 完整刀具库、工艺模板持久化到 SQLite
- 刀路优化：切割路径排序、微连接功能
- 新增后处理：PLT、兼容 AlphaCAM 的 CUT 格式

#### V0.3 完整版（对标 AlphaCAM 日常功能）

- DWG 图纸导入、批量零件导入
- 余料管理
- 工单历史存档、查询、另存
- 可视化后处理编辑器，直接在软件里修改 G 代码模板
- 快捷键自定义、操作界面优化

#### V0.4 MES 对接扩展版本（可选，后期开发）

- WebSocket/HTTP 接口对接 CenkorMes/LightMes
- 工单双向同步、用料统计回传、加工文件归档

### 5 风险备注

1. 只自研 2D 切割 CAM，不逆向 AlphaCAM 程序；.cut 格式仅做文件格式解析适配，规避版权风险
2. Python 仅作为调度层，几何、排料核心都是编译二进制库（OCCT / DeepNest），规避 Python 速度短板
3. 大几何数据前后端传输使用二进制 Buffer，禁止超大 JSON 报文传输

## 文档二：开发任务拆解清单（给 AI / 开发人员）

1. 搭建 Tauri2 + React + TS + Vite 基础项目，集成 PixiJS 2D 画布，实现视图平移、缩放、框选
2. Python FastAPI 后端脚手架 + SQLite 表结构设计（刀具表、工艺模板表、工单表）
3. DXF 解析模块：ezdxf 读取、轮廓提取、基础几何校验
4. OCCT 封装接口：轮廓闭合、断线合并、轮廓偏移（刀具补偿）、自相交检测
5. 零件对象数据结构定义，前后端二进制协议定义（WebSocket）
6. 手动排板模块：画布拖拽、旋转、锁定零件状态管理
7. DeepNest 进程封装，异步自动排料接口、利用率计算
8. 刀路生成模块：轮廓切割路径生成、起刀点、微连接、路径排序优化
9. 后处理引擎抽象层：模板渲染引擎，支持 NC / PLT / CUT 三种输出
10. 刀具库、工艺模板 UI 面板，增删改查、保存加载
11. 工单持久化模块：方案保存、读取、列表检索
12. 进度条、日志系统、报错弹窗
13. Tauri 打包脚本、Release 优化配置
14. MES 对接接口（预留，V0.4）
15. 测试用例：多种异形裁片、不同板材，上机验证 NC 文件
